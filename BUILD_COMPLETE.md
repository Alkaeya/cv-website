## 🚀 3-Step Deployment Path

### Step 1: Organize Files (30 seconds)
```bash
# Option A: Windows Batch
run-organization.bat

# Option B: Node.js
node organize-files-final.js

# Option C: Manual
Create "components" folder, move 9 .tsx files into it
```

### Step 2: Install & Test (2 minutes)
```bash
npm install
npm run dev
# Visit http://localhost:3000
```

### Step 3: Deploy to Vercel (5 minutes)
```bash
git add .
git commit -m "CV website"
git push origin main
# Go to vercel.com → New Project → Select repo → Deploy
```

## 📞 Support & Troubleshooting

### Common Issues & Solutions

**"components folder doesn't exist"**
→ Run: `node organize-files-final.js` or double-click `run-organization.bat`

**"npm install fails"**
→ Run: `npm cache clean --force` then `npm install` again

**"Port 3000 already in use"**
→ Run on different port: `npm run dev -- -p 3001`

**"Build fails on Vercel"**
→ Check components are in `components/` folder and imports are correct

**"Dark mode not working"**
→ Install next-themes: `npm install next-themes`
