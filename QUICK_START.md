Or copy this:

## ❓ TROUBLESHOOTING

**Icons not showing?**
→ Run `npm install lucide-react`

**Styling broken?**
→ Check Tailwind CSS is installed: `npm install tailwindcss`

**Components not found?**
→ Ensure files are in `components/` folder, not root

**Dark mode not working?**
→ Check browser dev tools for `dark` class on `<html>`
