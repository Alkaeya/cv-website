### 2️⃣ Update Your App (1 min)

**Open:** `app/page.tsx`

**Copy from:** `page-example.tsx`

**Or paste this:**
```typescript
'use client';

import Navbar from '@/components/Navbar';
import HeroSection from '@/components/HeroSection';
import AboutSection from '@/components/AboutSection';
import SkillsSection from '@/components/SkillsSection';
import ExperienceSection from '@/components/ExperienceSection';
import EducationSection from '@/components/EducationSection';
import ProjectsSection from '@/components/ProjectsSection';
import ContactSection from '@/components/ContactSection';
import Footer from '@/components/Footer';

export default function Home() {
  return (
    <main className="w-full">
      <Navbar />
      <HeroSection />
      <AboutSection />
      <SkillsSection />
      <ExperienceSection />
      <EducationSection />
      <ProjectsSection />
      <ContactSection />
      <Footer />
    </main>
  );
}
```

✓ Done! Your app is updated.

## ❓ If Something Goes Wrong

### Error: "Cannot find module 'lucide-react'"
→ Run: `npm install lucide-react`

### Error: "Components not found"
→ Check files are in `components/` folder, not root

### Dark mode not working
→ Check browser dev tools (F12) for `dark` class

### Website not loading
→ Check terminal for errors, usually simple fixes
